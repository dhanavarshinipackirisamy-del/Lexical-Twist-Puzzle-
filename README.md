# Lexical Twist Puzzle 🧩

Lexical Twist Puzzle is a Java-based console application that performs
string analysis and transformation based on user input.

---

## 📌 Features

- Accepts two single-word inputs
- Validates user input
- Checks reverse-word relationship
- Performs vowel transformation
- Combines words and counts vowels & consonants
- Rule-based output generation
- Modular OOPS design
